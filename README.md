# calorie-burnt-prediction
Calorie burn prediction using XGBoost Regressor

 About the Project

This project focuses on predicting calories burned during physical activity using Machine Learning. It was developed as a hands-on project while exploring machine learning concepts as an AI & Data Science student.

The model uses XGBoost Regressor, a gradient-boosting algorithm, to learn patterns from the available dataset and predict calorie expenditure based on input features.

Objective

To explore how machine learning regression techniques can be applied to predict calorie expenditure from activity-related data.

Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib and Seaborn 

 Project Workflow

1. Load and explore the dataset.
2. Preprocess the data as required.
3. Select input features and the target variable.
4. Train an XGBoost regression model.
5. Generate predictions and evaluate the model .

Model Algorithm: XGBoost Regressor

XGBoost is a gradient-boosting machine learning algorithm that combines multiple decision trees to make prediction
